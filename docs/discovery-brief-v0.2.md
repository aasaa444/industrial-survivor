## 3. 可逆方向（team_proposal，等待用户选择）

### 方向 A：连击引爆（打击链）
- **玩家承诺**：每一次命中都在堆叠，攒满即引爆全场。
- **30 秒核心循环**：走位引怪 → 自动攻击命中积累连击/层数 → 层数触发范围引爆 → 清屏回馈 → 下一波。
- **爽感来源**：打击反馈层叠、高频累积 + 引爆的即时兑现。
- **升级/构筑改动**：构筑围绕「叠层速度 vs 引爆倍率 vs 引爆范围」的三向取舍；局外成长改为解锁引爆流派而非单数值。
- **Demo 证明点**：单一引爆循环的爽感是否成立（层数、反馈、清屏密度）。
- **成本/风险**：打击反馈（震屏/音效/粒子）质量是成败关键；需要强 juice 投入。
- **迫使你作的选择**：爽感主轴是「累积的张力」还是「引爆的瞬间」。

### 方向 B：以血换屏（密度与代价）
- **玩家承诺**：刀尖跳舞，擦弹蓄能，用风险换清屏。
- **30 秒核心循环**：走位贴近弹幕/敌群 → 擦弹/近身积攒能量 → 高成本释放清屏技 → 代价（血量/资源）→ 走位回血/回收。
- **爽感来源**：风险-回报张力；越险越爽的擦弹奖励。
- **升级/构筑改动**：构筑围绕「近身收益 vs 生存成本」；局外成长改为解锁擦弹/兑换型机制。
- **Demo 证明点**：擦弹判定手感与风险-回报曲线是否让人「想更浪」。
- **成本/风险**：擦弹手感与判定边界难调；与「不为刁难玩家」的基调存在张力（B 的存废取决于 Q2）。
- **迫使你作的选择**：危险容忍度——玩家该被鼓励冒多大的险。

### 方向 C：构筑即清屏（技能拼图）
- **玩家承诺**：把 Build 搭成自动清屏机器，成型即解放。
- **30 秒核心循环**：拾取/合成 → 技能协同成型 → 场面自动扩大 → 换更高密度关卡验证构筑。
- **爽感来源**：协同成型与延迟满足；构筑本身成为清屏手段。
- **升级/构筑改动**：升级以「拼图/协同」为核心而非单发数值；局外成长与刷宝承载主要差异化（Build 蓝图/部件掉落）。
- **Demo 证明点**：一套 3-5 件协同 Build 的成型曲线是否有趣。
- **成本/风险**：内容量与数值面大，Demo 需砍到最小协同集；爽感兑现晚于 A/B。
- **迫使你作的选择**：爽感主力是「局内即时反馈」还是「局外构筑延迟满足」。

## 4. 剩余高价值问题（不重复已答项）

- **Q1（高潮曲线）**：单局爽感更想要「全程高压的层叠」（A）还是「周期爆发」（B）或「延迟释放」（C）？——直接判别 A/B/C。
- **Q2（危险容忍度）**：你希望玩家承担多大风险换来爽感（擦弹式鼓励 vs 回避惩罚式）？——决定 B 存废与「不为刁难玩家」基调的边界。
- **Q3（局外成长形态）**：局外成长做「轻度解锁」还是「重刷宝 Build 拼图」还是「无局外、单局即爽」？——当前最大信息缺口。
