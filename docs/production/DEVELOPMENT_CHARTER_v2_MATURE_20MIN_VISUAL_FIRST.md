## 1. 用户已确认的产品基线

以下内容来自用户明确确认，不是团队推测：

- 目标是一个约 20 分钟可连续游玩的成熟 Demo。
- 参考方向是《吸血鬼幸存者》和《土豆兄弟》。
- 保留当前的工业废墟、工业机械武器和机械敌人主题。
- 美术、UI、VFX、动画、场景构图和整体视觉完成度是最高优先级。
- 不允许粗糙的占位 UI、临时图形、调试字段或未完成视觉进入里程碑。
- 当前版本虽然可玩，但仍然是粗糙技术 Demo，下一阶段必须首先解决展示成熟度。

## 2. 产品承诺

陌生玩家第一次启动后，3 秒内能看出：

- 自己是谁；
- 自己在哪个工业空间；
- 敌人从哪里来；
- 自己应该如何移动；
- 当前目标是什么。

连续游玩 20 分钟时，玩家能够经历：

```text
进入游戏
-> 选择角色/初始武器
-> 移动与自动战斗
-> 获取经验和资源
-> 进行构筑选择
-> 应对波次和精英
-> 购买或强化装备
-> 面对 Boss
-> 胜利/失败
-> 结果统计
-> 重新开始或返回菜单
```

玩家应当因为构筑选择、敌群压力、武器反馈和视觉奖励而愿意继续玩，而不是因为系统数量多而继续玩。

## 3. 参考基准与适配原则

### Primary：Vampire Survivors

观察并适配：

- 3 秒内的角色/空间/威胁识别；
- 自动攻击与移动分工；
- XP 宝石吸取；
- 升级时暂停并进行 3 选 1；
- 武器等级和进化；
- 30/60/90 秒成长节奏；
- 敌群从稀疏到包围的压力曲线；
- 经验、升级、击杀、清场的音画层级。

选择：`adapt`。不复制角色、美术、文字、音乐或受保护表达。

### Secondary：Brotato

观察并适配：

- 构筑身份；
- 武器和被动组合；
- 属性取舍；
- 回合间商店；
- 资源使用；
- 波次压力和购买决策；
- 结果统计和重复游玩理由。

选择：`adapt`。第一版只吸收能够提高决策质量的功能，不复制完整商店复杂度。

### Local reference：当前 New_Game

保留：

- 工业废墟主题；
- Rail Pierce、Scatter Fan、Kinetic Pulse 的功能身份；
- 六分钟生存基础回路；
- canonical reset 和单一状态源；
- 当前已验证的 XP 1:1 收集规则。

替换：

- 裸文本 HUD；
- 临时升级卡；
- 调试式结果页；
- 低层级占位攻击特效；
- 内容直接堆在 `main.gd` 的结构。

## 4. 硬性非目标

在 20 分钟成熟 Demo 之前不做：

- 在线联机；
- 多人合作；
- 程序化无限地图；
- 复杂 Meta progression；
- 账号系统；
- 云存档；
- 多平台同步发布；
- 大量角色故事文本；
- 为了数量而加入的低质量武器和敌人。

视觉质量不足时，暂停内容扩展，不用新增系统掩盖视觉问题。

# 5. 最高优先级：视觉垂直切片

第一里程碑不是增加 8 把武器，而是先完成一段从启动到升级的成熟视觉体验。

## M0：视觉基线和产品重构

### 目标

建立所有后续内容必须遵守的视觉和 UI 语言。

### 必须交付

- 工业废墟视觉规范；
- UI 颜色、字体、字号和间距规范；
- 玩家、Walker、Brute、能量核心的尺寸规范；
- 攻击轨迹、命中、击杀、升级、精英和 Boss 的 VFX 规范；
- UI 图标尺寸和状态规范；
- 1280x720、1600x900、1920x1080 三个目标窗口基线；
- 第一屏静态构图稿；
- 升级卡构图稿；
- 结果页构图稿；
- 音频层级草案。

### 视觉硬门

以下任何一项不满足，M0 不通过：

- 首屏仍像调试场景；
- HUD 使用散落裸 Label；
- 升级卡没有图标、层级和状态；
- 玩家和敌人尺寸不协调；
- 攻击特效不能在背景上清晰读取；
- 截图存在空白默认布局、溢出、重叠或未完成区域。

### 证据

- L1：视觉 token 与尺寸表；
- L3：启动、HUD、升级卡的真实运行截图；
- 用户视觉评审：通过/拒绝。

## M1：正式 UI Foundation

### 玩家可见结果

启动后看到真正的游戏产品界面，而不是文本调试面板。

### 页面

- 主菜单；
- 角色/初始武器选择；
- 游戏 HUD；
- 升级选择页；
- 暂停页；
- 结果页；
- 设置页；
- 音频/键位说明页。

### HUD 组成

左上：

- 玩家头像/角色徽章；
- 生命条；
- 护甲或防护值；
- 当前等级。

顶部中央：

- 当前时间；
- 当前波次；
- 下一事件倒计时。

右上：

- 击杀数；
- Scrap 资源；
- 当前危险等级。

底部：

- 固定宽度 XP 条；
- 当前 XP / 下一等级 XP；
- 当前武器栏；
- 被动栏；
- 构筑标签；
- 临时状态效果。

### UI 行为

- 所有 UI 读取 authoritative read model；
- UI 不重新推导业务状态；
- 卡片、按钮、图标具备 hover/focus/pressed/disabled 状态；
- 键盘、鼠标和手柄路径统一；
- 窗口缩放不会溢出；
- 弹窗不会遮挡核心战斗信息；
- UI 所有文字可翻译，不硬编码在控制器逻辑中。

### 验收

- 3 个窗口尺寸截图；
- 键盘和鼠标真实交互；
- 暂停、返回、重开、结果页完整路径；
- L3 UI 视觉评审。

## M2：角色、敌人和场景视觉重做

### 玩家

至少包含：

- idle；
- 移动；
- 受击；
- 低生命；
- 升级；
- 胜利；
- 失败。

玩家必须具备明确轮廓、方向、脚下阴影、受击反馈和稀有状态反馈。

### 基础敌人

- Walker：基础追击；
- Brute：大型重型敌人；
- Spitter：远程压力；
- Charger：冲锋压力；
- Swarm Drone：数量压力。

第一批只做 5 种，但每种必须拥有完整：

- 轮廓；
- 动画；
- 受击；
- 击退；
- 死亡；
- 生成反馈；
- 威胁层级。

### 场景

工业废墟地图必须包含：

- 地面层；
- 可识别地标；
- 道路/空间层级；
- 机械残骸；
- 危险区域；
- 边界或远景提示；
- 前景遮挡控制；
- 玩家和敌人可读性保证。

禁止只放一张背景图作为最终地图。

## M3：战斗体感和 VFX

### 三个现有武器先达到成熟质量

#### Rail Pierce

- 明确发射起点；
- 高速直线轨迹；
- 穿透多个敌人；
- 每个目标独立命中反馈；
- 穿透末端衰减；
- 清场时有方向性扩散。

#### Scatter Fan

- 扇面角度稳定；
- 多条轨迹可分辨；
- 不遮挡玩家；
- 目标命中层级清晰；
- 扇面扩大和等级变化可观察。

#### Kinetic Pulse

- 环形冲击波；
- 敌人被推出；
- 击退距离清晰；
- 近身脱围身份明确；
- 冲击结束有残留衰减。

### 通用 VFX

- 命中闪光；
- 伤害数字；
- 击退拖尾；
- 敌人死亡分解；
- 能量核心掉落；
- 能量核心吸取轨迹；
- 升级确认；
- 升级应用；
- 精英登场；
- Boss 预警；
- 胜利和失败转场。

### VFX 硬门

- 特效不能是永久 Line2D 残留；
- 不能因为粒子数量增长导致帧率持续下降；
- 不能把所有反馈都做成同一颜色和同一闪光；
- 不能遮挡玩家、敌人和关键 UI；
- 每种武器必须有独立可读的视觉身份。

# 7. 工程架构重构

当前 `runtime/main.gd` 不再允许承载所有新系统。

目标结构：

```text
runtime/
  game_session.gd
  progression_controller.gd
  combat_controller.gd
  enemy_director.gd
  wave_director.gd
  weapon_controller.gd
  pickup_controller.gd
  result_controller.gd

ui/
  hud_controller.gd
  upgrade_screen.gd
  pause_screen.gd
  result_screen.gd
  main_menu.gd
  shop_screen.gd

content/
  weapons/
  upgrades/
  passives/
  enemies/
  waves/
  bosses/
  characters/

presentation/
  combat_vfx.gd
  damage_numbers.gd
  audio_presenter.gd
  screen_feedback.gd
```

工程硬规则：

- 一个玩家状态只有一个 production writer；
- UI 只读 authoritative read model；
- 武器、敌人、波次、升级都数据驱动；
- 新功能必须先有 integration contract；
- `main.gd` 只负责场景编排，不再继续堆业务；
- 所有 reset 必须走 canonical reset；
- 所有生产修改经 GDMCP；
- 每次视觉资源修改必须验证所有消费者。

# 9. 视觉优先级排序

如果资源不足，严格按此顺序：

1. HUD、升级卡、主菜单、结果页；
2. 玩家角色和敌人轮廓；
