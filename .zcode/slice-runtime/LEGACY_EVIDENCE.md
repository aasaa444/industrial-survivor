# Legacy Pilot Evidence

The `SLICE-PILOT-*` directories were collected before the strict candidate identity,
L3 sidecar, and tool-owned session-result contracts were introduced. They remain for
audit only and are classified as `legacy_identity_partial`.

They must not be used to advance a strict Slice Runtime transition. Recollect L2/L3
evidence with the current candidate identity file, transaction ID, protected native
sidecar, successful session result, and artifact hash validation.
